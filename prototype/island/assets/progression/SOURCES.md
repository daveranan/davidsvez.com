# Coin audio source

`coin-pickup.wav` is copied unchanged from the user-supplied Lightkeeper project:

`F:/GameProject/Archive/Lightkeeper/Assets/Content/Audio/SFX/Items/Pickup/CoinPickup_001.wav`

It is not requested or played before the parent enables audio after a visitor's
gesture. The cue is quiet, short, and can be muted through the shared sound
control. Coin geometry, shovel, dig markers, treasure props, and rounded northern
terraces are authored directly for this website module.

Progress is browser-local game state. It does not buy, restrict, or unlock access
to portfolio pages, and has no connection to payments or any external account.
